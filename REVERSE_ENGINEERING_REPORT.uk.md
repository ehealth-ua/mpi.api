## Виявлена архітектура
Додаток Phoenix/Elixir для Master Patient Index (ідентифікація пацієнтів) системи eHealth України. Архітектура umbrella з декількома додатками Mix. Зберігає особисті дані пацієнтів і надає API для пошуку, збігу та дедуплікації.

Основні компоненти:
- `apps/core/` — додаток ядра (бізнес-логіка, моделі, RPC)
- `apps/candidates_merger/` — злиття кандидатів, Kafka producer
- `config/` — конфігурація за середовищем (dev/test/prod)
- `bin/` — скрипти релізу
- `rel/` — artefакти релізу
- `Dockerfile` / `Dockerfile.deduplication` — образи Docker

## Технології та залежності
- Elixir / Phoenix
- Erlang/OTP
- PostgreSQL 9.6+
- Kafka
- Mix (інструмент збирання)
